# Mi Página Personal - Taller HTML

## Descripción
Página web básica creada con HTML que muestra mi presentación personal, 
intereses, imagen y enlaces favoritos.

## Contenido
- Encabezado con mi nombre
- Párrafo de presentación
- Lista de intereses
- Imagen
- Enlaces a redes y sitios favoritos

## Tecnologías usadas
- HTML5

## Cómo verlo
Abrir el archivo `index.html` en cualquier navegador.
